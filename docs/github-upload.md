# Publish the portfolio repository

Suggested name: `bakery-stock-reconciliation-powerbi`

Suggested description:
> Power BI case study for central bakery and outlet stock reconciliation, wastage monitoring, and daily variance investigation using DAX.

Suggested topics:
`power-bi`, `dax`, `retail-analytics`, `inventory-management`, `bakery`, `business-intelligence`, `data-analytics`, `portfolio`

1. Extract the ZIP on your computer.
2. In your GitHub account, create a new repository with the suggested name and description. Choose visibility after reviewing permission to share the screenshots.
3. Select **Add file → Upload files** in the new repository.
4. Upload the contents inside the extracted project folder, keeping the `assets`, `docs` and `dax` directories. `README.md` should be at the repository root.
5. Commit the upload. Open the repository homepage and confirm both images display.
6. Add the suggested topics in the About section and pin the repository on your profile if desired.

The `.gitignore` excludes common local credentials, raw data and Power BI binaries. GitHub web uploads do not enforce it: review files manually before uploading. No license has been added because ownership and redistribution rights for the original business work have not been established.

This package was prepared locally; it has not been published to a GitHub account.
